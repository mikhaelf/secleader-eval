# Scoring guide (internal — do not print in the report)

| Stars | Meaning                                           |
| ----- | ------------------------------------------------- |
| ★★★★★ | Exceptional — clear positive signal, well-sourced |
| ★★★★☆ | Strong — mostly positive, minor gaps              |
| ★★★☆☆ | Neutral / mixed — warrants more diligence         |
| ★★☆☆☆ | Weak — notable concerns                           |
| ★☆☆☆☆ | Red flag — significant risk or dealbreaker        |

## Recommendation thresholds (average of all 5 dimensions)

- Average ≥ 4.0 → **PURSUE**
- Average 3.0–3.9 → **LEARN MORE**
- Average < 3.0 → **PASS**

## Hard overrides

- **Not full-time with benefits** (contract, 1099, part-time, no benefits) → **PASS**, regardless of scores. State the reason in the recommendation.
- If employment type cannot be confirmed → do **not** invoke override; cap at **LEARN MORE** and list "confirm full-time with benefits" as the first interview question.
- **`profile.md` hard passes** (if present) → **PASS** when matched; state which rule triggered.

## Other rules

- Work type (onsite/hybrid/remote) is **not scored** — report neutrally in Work Arrangement only.
- Be conservative: unknown team data → do not score above ★★★☆☆ on Team / Function Maturity.
- An unverified data point is not a positive signal.
