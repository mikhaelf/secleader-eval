# Candidate profile (optional)

Copy this file to `profile.md` in the same directory as the installed skill to apply personal overrides on every eval.

```markdown
# My eval preferences

Function: security
Target level: VP / Head / Director
Location: remote preferred; onsite SF acceptable for VP+ only

Comp floor: $350K total comp (base + bonus + annualized equity)
Hard pass:
- Contract or 1099 roles
- Field-CISO / sales-overlay roles with no internal headcount
- No benefits

Always ask in recommendation:
- MIP/STI target % for the band
- Equity % fully diluted and refresh policy
```

Delete this example file or leave it unused; only `profile.md` is read at runtime.
